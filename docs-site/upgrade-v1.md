# Upgrade to v1.0.0

The `/v1` API request and response shapes are unchanged. v1.0.0 adds
conservative Sharp defaults and stable API compatibility guarantees.

See the repository's [upgrade guide](https://github.com/erolsenol/image-craft-service/blob/master/docs/upgrade-v1.md)
for Docker, SDK, configuration, and health-check steps, plus the
[deprecation policy](https://github.com/erolsenol/image-craft-service/blob/master/docs/api-stability.md).
